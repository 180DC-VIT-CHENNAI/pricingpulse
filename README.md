# PricingPulse

PricingPulse is a small, local-only dynamic pricing simulator built for an open source security hackathon. It demonstrates pricing calculations, tier configuration, discount analysis, and saved user scenarios.

## Setup

```bash
npm install
npm start
```

Open <http://localhost:3000> in a browser. The app uses a local SQLite database file named `pricingpulse.db`.

## Features

- Price elasticity simulation
- Free, Pro, and Enterprise tier builder
- Discount impact calculator
- Basic registration and login
- Saved scenarios per user
- Local SQLite persistence

## Hackathon Rules

1. Fork the repository.
2. Pick one issue to work on.
3. Submit one pull request per fix.
4. Include the issue number in the pull request description.
5. Add tests or clear manual testing notes.
6. Keep changes focused and beginner-friendly.

Please use the pull request template and do not submit exploit scripts.
