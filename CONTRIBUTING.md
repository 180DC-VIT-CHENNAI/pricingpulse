# Contributing

Thanks for helping improve PricingPulse.

## Pull requests

- Fork the project and create a focused branch.
- Choose one issue and make one fix per pull request.
- Explain the original issue, the change, and how you tested it.
- Keep the app runnable with `npm install && npm start`.
- Avoid unrelated formatting or dependency changes.
- Do not include real credentials, malware, exploit automation, or third-party targets.

Use `.github/PULL_REQUEST_TEMPLATE.md` when opening a pull request.
